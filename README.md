# Icon Tester

APK de prueba para identificar qué icono muestra el smartwatch T900ultra/LY736
para cada ID de icono del protocolo BLE (comando 18, key 18).

Uso:
1. Instalar el APK.
2. Pulsar CONECTAR (se conecta al reloj por BLE, MAC 9A:22:33:04:80:E8).
3. Ingresar un ID de icono o usar los botones rápidos 1–20.
4. Pulsar ENVIAR PRUEBA y mirar qué icono muestra el reloj.
5. Anotar el resultado por cada ID.
